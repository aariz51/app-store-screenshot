# Reference analysis

These files record how the five styles were derived. Five published store screenshot sets were measured: panel grids, normalised element boxes, sampled colours, type metrics, device treatment and story order. Each finding is tagged OBSERVED, MEASURED, INFERRED or UNKNOWN.

| [03-archetypes-decision-engine-layouts.md](03-archetypes-decision-engine-layouts.md) | Archetype library, weighted style decision engine, 12-layout library |
